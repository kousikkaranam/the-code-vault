# the-code-vault
A growing vault of code, algorithms, problem-solving patterns, and software engineering interview practice.

## Java

Requires JDK 25+. Each file in `java/` is a standalone program with its own `main`; there is no build step.

```sh
java java/odd_even.java
```

To add a new problem, copy `java/_template.java` to `java/<problem_name>.java` and run it the same way.
In IntelliJ, open any file and click the green ▶ next to `main`.
